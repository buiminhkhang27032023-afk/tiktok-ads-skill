# tiktok-ads-skill

Skill tái sử dụng `tiktok-ads-messaging`: tạo, chẩn đoán và tối ưu chiến dịch TikTok Ads tối ưu Cuộc trò chuyện qua TikTok Direct Message.

## Cấu trúc
- `SKILL.md` – skill chính (frontmatter + quy trình, checklist, tối ưu).
- `references/notes.md` – ghi chú chi tiết 74 mục kèm link nguồn TikTok Help Center/Guides.

## Dùng
Copy thư mục vào thư mục skills của agent (vd. `~/.claude/skills/tiktok-ads-messaging/` hoặc tương đương). Nội dung chung, không chứa ID tài khoản, tên khách hàng hay bí mật.
